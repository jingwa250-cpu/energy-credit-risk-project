## Project Structure
- data/ → raw and processed datasets
- src/ → Python scripts
- outputs/ → generated reports and charts

## Example Workflow
1. Load market data
2. Simulate counterparty positions
3. Calculate exposure and collateral requirements
4. Generate margin call decisions

## Why This Matters
This project mirrors how credit analysts monitor counterparty exposure and collateral requirements in energy trading firms.
